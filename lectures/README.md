## Coverage and exclusions

- **Topic 6, electrochemistry:** listed in the current syllabus, but no lecture-slide resource was present on the inspected course page. The electrode-potential reference sheet is included; this does not replace the missing slides.
- **Tutorial 3 and assignment 2:** no separate answer PDF was linked on the inspected course page.
- **Personal data:** student submissions, submission receipts, feedback, grades, and account credentials are not part of this collection.
- **Videos:** Moodle recording links are catalogued below rather than exported as video files.
